Warp Dodgeball — Game Design Spec
• Nests are powerful (you can see over all cover), but climbing the ladder takes about 2 s
during which you can't throw, catch, or dodge.
• Cover is placed so that every hiding spot can be reached by at least one portal angle.
Hiding is never fully safe.
• Nest decks count as ground: a ball that lands on a deck goes dead.
Technical architecture and Blender pipeline
Blender is the asset tool and Godot 4 is the game engine. Blender no longer has a built-in
game engine (it was removed in version 2.80), so Claude Code should model in Blender
and run the game in Godot, which is free, text-based (easy for Claude Code to edit), and
imports Blender files directly.

Blender conventions
• Export each asset as .glb into the Godot project's assets folder; Godot re-imports on
change.
• Name collision meshes witha -col suffix so Godot builds collision shapes
automatically.
