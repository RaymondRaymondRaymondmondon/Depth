The generator
For endless play: it picks a world, lays 3-7 platforms on a grid with the world's pieces,
guarantees every spawn can reach every other, adds 1-3 hazards and 1-2 movers, and rt-Jns
a reachability check with the real movement code (the parkour side's
- -verify
approach). Generated stages are marked and can be saved to the editor if the group liked
one.
Finale stages
Each world has three finales: twice the size, the wall at 30 s, and a set piece (the propeller
starts, the Lobster rises, the kraken reaches up from the drop-off, the Wyrm surfaces in
the plaza, the leviathan's lure appears, closing time with the whole bar thrown in).
New features
Trinkets
Each stick picks one trinket in the lobby for the match (or lets the game pick). A trinket is
one small, visible edge; everyone can see what everyone took, so the counter-play is open.
