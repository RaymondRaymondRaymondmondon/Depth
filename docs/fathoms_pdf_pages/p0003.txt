Faction selection rules. Duplicate factions are allowed. A Random pick shows a question
mark until the match starts. Each player sees the others' picks only when the host locks
the lobby, so no one counter-picks at the last second.
Handicaps. The host can give any player +10% to +30% gather rate. This keeps games fun
when skill levels differ a lot among friends.
Map and archipelago generation
Maps are tile grids generated from a seed with rotational symmetry, so every player gets
the same home island and the same distances to key sites. The center of the map holds
the richest and most dangerous sites.
