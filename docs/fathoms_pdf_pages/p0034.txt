Technical requirements for Claude Code
• Library. Valve's open-source GameNetworkingSockets (C++): reliable and unreliable
messages, encryption, and ICE/STUN support for connecting through routers. ENet is
a simpler fallback.
• Message types. Reliable ordered: commands, chat, diplomacy, lobby changes.
Unreliable: world updates (a lost one is replaced by the next).
• World updates. Delta-compressed: only units that changed since the client's last
acknowledged update are sent. Positions quantized to 1/16 tile.
• Fog-of-war filtering. The host never sends a unit's position to a player who can't see it.
This saves bandwidth and prevents map-hacking.
• Bandwidth estimate. A busy 6-player match (about 360 units, 150 buildings, neutrals)
needs roughly 10-20 KB/s per client after filtering, so the host uploads about 1 Mbps.
That fits normal home internet.
